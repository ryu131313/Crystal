Crystal - Legend of Mir 2 client
================================

Needs
- Windows 10 or 11, 64-bit.
- .NET 8 Desktop Runtime (x64): https://dotnet.microsoft.com/download/dotnet/8.0
  ("Desktop Runtime", Windows x64 installer).

Start
1. Unzip this folder somewhere you can write to (for example Documents\Crystal), not Program Files.
2. Run Client.exe.
3. The game opens straight away and downloads its files while it runs: on the first start the login screen fills in
   as its pictures arrive, and new maps and monsters appear as they download. Later starts only download what changed.
   When a new version of the game is ready you are asked to restart (or it is applied when you exit).

Your settings are saved in Mir2Config.ini in this folder.
